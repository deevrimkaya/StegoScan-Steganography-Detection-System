# 🛡️ StegoScan: Web Tabanlı Steganografi Tespit ve Adli Bilişim Analiz Sistemi

Bu proje, Bilişim Güvenliği Teknolojisi önlisans mezuniyet çalışmam kapsamında geliştirilmiş web tabanlı bir steganografi tespit ve adli bilişim analiz sistemidir[cite: 3].

## 🚀 Proje Hakkında ve Özellikler
StegoScan, web tarayıcıları üzerinden erişilen görsellerin içerisindeki gizli verileri tespit etmek ve adli bilişim analizi sunmak amacıyla geliştirilmiştir[cite: 3].

- **Chrome Extension (Manifest V3):** Kullanıcı dostu arayüz ile isteğe bağlı görsel analizi[cite: 3].
- **Python Flask & Pillow:** Arka planda LSB (Least Significant Bit), Entropi ve EOF (End of File) analiz motoru[cite: 3].
- **Adli Bilişim Paneli (Dashboard):** Gerçek zamanlı risk skorlaması (%0-%100) ve tespit raporlama[cite: 3].

📁 **Sistemin detaylı mimarisi, test sonuçları, ekran görüntüleri ve proje raporu dosya listesindeki dokümanda yer almaktadır.**[cite: 3]
